===============================================================================
 CATPPUCCIN MOCHA (BLUE ACCENT) COLOR PALETTE
===============================================================================

Description:
  A soothing, dark theme with vibrant pastel accents from the official Catppuccin
  Mocha color scheme palette, featuring a deep navy-slate base and a signature
  blue highlight color.

-------------------------------------------------------------------------------
COLOR CODES & ROLES
-------------------------------------------------------------------------------

#1e1e2e  (RGB: 30, 30, 46)    - Base / Main Background
                                Application canvas, editor background, terminal background.

#181825  (RGB: 24, 24, 37)    - Mantle / Surface Background
                                Headerbars, titlebars, top bars, window frames.

#11111b  (RGB: 17, 17, 27)    - Crust / Deep Background
                                Sidebar panels, popups, bottom status bars.

#313244  (RGB: 49, 50, 68)    - Surface0 / Card Background
                                Active buttons, input fields, widget containers, hover states.

#45475a  (RGB: 69, 71, 90)    - Surface1 / Selection Background
                                Text selection, active list items, process selection.

#6c7086  (RGB: 108, 112, 134) - Overlay0 / Subtle Borders
                                Border lines, divider rules, inactive tab labels.

#a6adc8  (RGB: 166, 173, 200) - Subtext0 / Inactive Text
                                Secondary labels, disabled control text, inactive titlebars.

#cdd6f4  (RGB: 205, 214, 244) - Text / Main Foreground
                                Primary text, icon fills, default readable labels.
